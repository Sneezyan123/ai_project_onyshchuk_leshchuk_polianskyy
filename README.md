# Тематичне моделювання Telegram-пропаганди

Курсовий проєкт з ШІ, УКУ. Команда: Онищук Артем, Полянський Іван, Лещук Роман.
Ментори: Косован Олександр, Корець Христина.

## Про що проєкт

Ми беремо воєнні Telegram-канали і дивимось, про що вони пишуть. Порівнюємо чотири групи:
прокремлівські канали, російську й білоруську опозицію, українські канали та білоруські
провладні. Питання прості: чим відрізняються їхні набори тем і що змінилось після 24.02.2022.

Тематичні карти Telegram уже робили, тому наша мета трохи далі: після тем дійти до тверджень
(«хто що про кого каже»), бо одну й ту саму подію, наприклад обстріл українського міста,
пишуть усі сторони, а різниця між ними видна лише в оцінці. Зараз зроблена перша частина:
вибірка, EDA, LDA як baseline, BERTopic, порівняння груп і зсув до/після вторгнення.
Витягання тверджень ще попереду.

Звіт до мідтерму: [docs/midterm/report.md](docs/midterm/report.md). Пропоузал:
[docs/proposal/](docs/proposal/).

## Головні результати

- **Вибірка:** 423 101 пост з 1 256 каналів за 24.02.2021-23.02.2023, без форвардів і дублікатів.
  Групи: Кремль 403 канали, опозиція 176, Україна 639, Білорусь 38.
- **LDA проти BERTopic:** LDA (K=20) дає розмиті теми й ділить корпус за мовою (97% україномовних
  постів потрапляють в одну тему). BERTopic (235 тем) читається краще, стабільніший між запусками
  (ARI 0.68 проти 0.41), але 59% постів лишаються в шумі. За NPMI на малому референсі LDA
  виграє, проте на повному корпусі обидві моделі майже рівні (0.179 і 0.173), тож розрив -
  артефакт референсу.
- **Кремль і опозиція:** відстань між їхніми розподілами тем (JSD) 0.26 при випадковому рівні
  0.07. Кремль пише про губернаторів, Кадирова, збори на армію й Крим, опозиція - про
  політв'язнів, суди, «іноагентів» і незалежні медіа.
- **Білорусь:** ближча до Кремля (0.41), ніж до опозиції (0.43), але не копія. Після 24.02
  Білорусь і Кремль зблизились: 0.48 перед вторгненням, 0.36 після.
- **Після 24.02:** найбільше змінилась Україна (у 6.5 раза більше за звичайний дрейф), далі
  Кремль (у 3), опозиція (у 2.4) і Білорусь (у 1.6). Найбільше просів ковід.
- **Мова - головне обмеження:** приблизно половина відстані між Кремлем і Україною пояснюється
  мовою, а не змістом. Це головне, що треба розв'язати до фіналу.
- **Переклад англійською** виграшу не дав, тож працюємо з оригіналом.

Усі деталі, перевірки й обмеження - у звіті.

## Дані

Три датасети, усі під CC BY 4.0: Pro-/Anti-Kremlin Telegram Dataset (Bawa & Kursuncu),
Russian and Ukrainian War-related Telegram Channels (Kyrychenko, Zenodo) і Telegram for

ліцензії й обмеження описані в [data/README.md](data/README.md).

## Як запустити

Потрібен Python 3.12. GPU бажаний: у нас RTX 3050 на 4 ГБ, цього вистачає. Вільного місця
треба з запасом, самі архіви важать ~53 ГБ.

```bash
python -m venv .venv
.venv/Scripts/pip install torch --index-url https://download.pytorch.org/whl/cu124
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python src/run_all.py
```

Версію torch підбирайте під свою CUDA. `run_all.py` проганяє все по черзі, а кожен крок можна
запустити окремо з папки `src/`:

| Крок | Скрипт | Орієнтовний час |
|---|---|---|
| завантаження з figshare (4.8 ГБ) | `download.py` | ~10 хв |
| завантаження з Zenodo (48 ГБ) | `download_zenodo.py` | ~35 хв |
| групи каналів | `groups.py` | секунди |
| потокова вибірка з обох датасетів | `sample.py` | ~20 хв |
| language ID + EDA | `eda.py` | ~1 хв |
| лематизація ru/uk | `lemmatize.py` | ~6 хв |
| LDA, K = 20/40/60/80 + стабільність | `lda.py` | ~30 хв |
| ембединги multilingual-e5-base | `embed.py` | ~35 хв |
| UMAP + HDBSCAN + c-TF-IDF, 4 гранулярності | `topics_bertopic.py` | ~25 хв |
| порівняння груп, зсув після 24.02, перевірки | `analysis.py` | ~5 хв |
| переклад проти оригіналу | `translation_exp.py` | ~10 хв |
| когерентність, мова, стабільність | `coherence_check.py`, `lang_split.py`, `stability.py` | ~35 хв |

Seed скрізь 42. Таблиці зберігаються в `results/tables/`, графіки в `results/figures/`.
Повний прогін без завантаження займає години 2.5-3.
